You found the draft. It is not linked from the articles listing, because the listing filters on the `draft` frontmatter flag, but the page itself renders normally. That is exactly how drafts should behave while you work on them.

## Why this entry exists

The draft flag is a boolean in the collection schema, so it shows up in the entry editor as a toggle. Flip it off, save, and this article appears on the listing; flip it back and it disappears again. A whole publish/unpublish cycle without touching a file by hand.

That is the entire point of this post. It is scaffolding pretending to be prose, but then again, so is the rest of this site.
