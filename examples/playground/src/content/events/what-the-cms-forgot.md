Every content management system promises the same thing and then puts a form between you and the page. This talk is about the shape of that gap.

## The argument

The admin panel was a reasonable answer to a problem we no longer have. When the page and its source were separated by a database and a template language, a separate editing surface was the only surface available. Static sites put the source back within reach — a file on disk, in a tree you already version — and the panel stopped earning its place.

## What replaces it

Not another panel. The page itself, with the file underneath it, and git as the undo history you already trust.
